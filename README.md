# Zeitra

Bilingual (EN / 中文) time & date toolkit — a suite of 100% client-side calculators and converters.

- World Clock · Time Zone Converter · Meeting Planner · Age Calculator
- Date Difference · Date Calculator · Countdown · Duration Calculator

No sign-up, no upload, privacy-first. Runs entirely in the browser via the native `Intl` API (IANA time zones, DST-aware).
