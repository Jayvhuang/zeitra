About this tool

Find overlapping working hours across multiple time zones so global teams can pick a meeting time that suits everyone.

查找多个时区的工作时间重叠，帮助全球团队选出对所有人合适的会议时间。

This tool is part of Zeitra, a free, private, bilingual (EN / 中文) time & date toolkit that runs entirely in your browser — no login, no tracking.

Frequently asked questions

How many time zones can I compare?

You can add as many time zones as you like; rows where everyone is within working hours are highlighted in amber.

Can I set custom working hours?

Yes. Set the work start and end hour for the whole group; the planner recalculates the overlap instantly.

Does it respect daylight saving time?

Yes. Each zone's local time is computed with the browser's timezone database, including DST.
